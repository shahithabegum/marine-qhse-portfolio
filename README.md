# Marine 3D Portfolio — Mohammed Fazil

## Run locally
1. Install Node.js 20 or later.
2. Extract the ZIP and open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Production build
Run `npm run build`, then `npm run preview`.

## Features
- Interactive Three.js / React Three Fiber ship model (drag to rotate)
- Framer Motion section animations
- Navy / gold marine-inspired design
- Responsive mobile navigation
- Experience, skills, education, certifications and project sections
- Download CV link and contact form

## Resume PDF
Place your final resume PDF in `public/` named `MOHAMMED-FAZIL-RESUME.pdf`.
The contact form uses `mailto:` and opens the visitor's email app; it does not send directly from a server.

## Customize
Update the resume information in `src/App.tsx`. Skill percentages are illustrative portfolio indicators. The 3D ship is a stylized mesh model made from Three.js primitives.
